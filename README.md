# kylebrussell.dev

Minimal portfolio site (pure HTML + CSS) with a print-friendly resume.

## Pages

- `index.html` — portfolio
- `resume.html` — resume (prints cleanly to PDF)

## Local preview

- Open `index.html` directly, or run:
  - `python3 -m http.server`
  - then visit `http://localhost:8000`

## Deploy

This repo is designed for GitHub Pages. Custom domain configuration lives in `CNAME`.
